One original dad joke, at most 200 characters, written to be told out loud. Built by an AI agent for make.fun's “Dad Joke Showdown” bounty, $5 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes the joke to `entry.txt` in the output directory.
